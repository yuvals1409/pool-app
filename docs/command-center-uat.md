# UAT — מרכז ניהול בית הספר (Stream Line)

> **מטרה:** בדיקה ידנית עם מנהלת בית הספר לפני שחרור סופי.  
> **תפקיד נדרש:** Admin או Owner (מפתח מערכת).  
> **תאריך יצירה:** 2026-06-20

## לפני שמתחילים

- [ ] התחברות כמנהל (לא משרד, לא מדריך)
- [ ] ודאו שיש נתונים אמיתיים: עונה פעילה, הרשמות, מפגשים, לידים
- [ ] סמנו ✓ / ✗ / הערות בכל שורה

## הרשאות (אימות מהיר)

| בדיקה | Admin | Office |
|-------|-------|--------|
| גישה לטאב **ניהול** ולכל הדוחות | ✓ | ✗ |
| גישה לטאב **משרד** | ✓ | ✓ |
| וידג'ט התראות במשרד — צפייה + "טופל" | ✓ | ✓ |
| RPCs אנליטיקה (דשבורד, כספים וכו') | ✓ | ✗ (שגיאה / ריק) |

---

## 1. סקירה כללית

**טאב:** ניהול → **סקירה כללית** (`dashboard`)

- [ ] שורת KPI נטענת: תלמידים פעילים, קבוצות, מדריכים, תפוסה, חדשים/עוזבים, שיעורים פרטיים
- [ ] סינון תקופה: היום / השבוע / החודש משנה את מגמת התפוסה
- [ ] כרטיס מדד בריאות מציג ציון וצבע (🟢/🟡/🔴)
- [ ] קישור "פירוט והגדרות" פותח את טאב מדד בריאות
- [ ] אין טעינה אינסופית (spinner נשאר פעיל)

---

## 2. תלמידים ודמוגרפיה

**טאב:** ניהול → **תלמידים** (`students`)

- [ ] גרפים/טבלאות: כיתה, מגדר, ותק (6 דליים)
- [ ] סינון לפי עונה עובד
- [ ] סינון סטטוס: פעילים / הכל / בוטלו
- [ ] ייצוא CSV מוריד קובץ תקין

---

## 3. כספים

**טאב:** ניהול → **כספים** (`finance`)

- [ ] סה״כ הכנסות, לקוחות ששילמו, ממוצע ללקוח
- [ ] פילוח לפי תחום: שנתי / קיץ / פרטני / מבדק
- [ ] גרף מגמה חודשית
- [ ] סינון תאריכים (חודש / שנה) משנה את הנתונים
- [ ] ייצוא CSV

**לא בגרסה זו:** חובות פתוחים

---

## 4. כרטיס תלמיד 360°

**טאב:** ניהול → **הרשמות** (`enrollments`) או חיפוש לקוחות

- [ ] לחיצה על תלמיד פותחת כרטיס / פאנל פרטים
- [ ] פרטים אישיים: שם, מגדר, כיתה, תאריך לידה
- [ ] קבוצה נוכחית + מדריך
- [ ] אחוז נוכחות (אם יש היסטוריה)
- [ ] סטטוס תשלום

---

## 5. מדריכים (אנליטיקה)

**טאב:** ניהול → **אנליטיקת מדריכים** (`instructors`)

- [ ] טבלת מדריכים: תלמידים, קבוצות, שעות, תפוסה, נוכחות %, שימור, הכנסה לקאנטרי
- [ ] סינון תקופה (מתאריך / עד תאריך)
- [ ] drill-down לשורה בודדת — פרטים נוספים
- [ ] עריכת `hired_at` (ותק) נשמרת

**הערה:** שכר מדריכים בטאב נפרד (`payroll`) — לא חלק מסעיף זה.

---

## 6. נוכחות והתראות

### 6א. נוכחות

**טאב:** ניהול → **נוכחות** (`attendance`)

- [ ] מעבר בין תצוגות: אירועים / סיכום
- [ ] סיכום לפי: תלמיד / קבוצה / מדריך
- [ ] אחוז נוכחות מוצג (לא רק ספירות גולמיות)
- [ ] סינון תאריכים וחוג

### 6ב. התראות

**טאב:** ניהול → **התראות** (`alerts`)

- [ ] רשימת התראות פתוחות (היעדרויות 3 ברצף, סיכון עזיבה, תפוסה גבוהה)
- [ ] סינון לפי סוג וחומרה
- [ ] כפתור "רענון התראות" יוצר התראות חדשות (אם יש תנאים)
- [ ] "טופל" מסיר מהרשימה

**משרד:** טאב **משרד** → וידג'ט התראות (עד 5) + acknowledge

---

## 7. שיווק וצמיחה

**טאב:** ניהול → **שיווק** (`marketing`)

- [ ] משפך: פניות → מבדק → עבר → נרשם
- [ ] אחוזי המרה בין שלבים
- [ ] pie chart מקורות הגעה
- [ ] תחזית בסיסית לעונה הבאה (תפוסה + רשימת המתנה)
- [ ] ייצוא CSV

---

## 8. תפעול יומי

**טאב:** ניהול → **תפעול יומי** (`operations`)

- [ ] בחירת תאריך מציגה מפגשי היום
- [ ] לכל מפגש: מדריך (כולל מחליף), רשומים/capacity, סטטוס מילוי
- [ ] ביטולים השבוע — רשימה
- [ ] השלמות מתוכננות — רשימה

---

## 9. תשתית דמוגרפיה (איסוף נתונים)

**לא מסך נפרד** — נבדק בהרשמה:

- [ ] הרשמה חדשה (משרד / מבדק) דורשת מגדר
- [ ] כיתה נדרשת מתחת לגיל 18
- [ ] מעל גיל 18 — כיתה אופציונלית

---

## 10. מדד בריאות

**טאב:** ניהול → **מדד בריאות** (`health`)

- [ ] ציון חודשי + צבע (ירוק / צהוב / אדום)
- [ ] פירוט רכיבים: תפוסה, גידול (חדשים/עוזבים)
- [ ] השוואה לחודש קודם
- [ ] גרף 12 חודשים אחרונים
- [ ] הגדרות: משקלים (סכום 100%), ספי צבע — נשמרות

---

## לא בגרסה זו (מסומן במפורש)

- [ ] חובות פתוחים / דוח חוב
- [ ] קבוצות מבוגרים / פעילויות מיוחדות כתחום נפרד
- [ ] Office עם גישה לדוחות אנליטיקה
