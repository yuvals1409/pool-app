# מילון מדדים — מרכז ניהול בית הספר (Stream Line)

> **סטטוס:** מאושר ויושם — migration הורץ ב-2026-06-20  
> **תאריך:** 2025-06-20

## הגדרות מדדים

| מדד | הגדרה |
|-----|--------|
| **תלמיד פעיל** | רשום לחוג/קורס (`enrollment.active = true`) **ו** יש לו לפחות אירוע נוכחות `present` בחוג/קורס הנוכחי |
| **ספירת תלמידים** | לפי `participant_id` ייחודי — ילד בשני חוגים נספר **פעם אחת** |
| **עזב** | ביטול הרשמה (`active = false`, `cancelled_at` מתמלא) |
| **הכנסה** | רק הרשמות/שיעורים עם `payment_status = paid` × מחיר המוגדר |
| **חובות** | לא בשימוש כרגע — כניסה מותנית בתשלום (ברקוד בתוקף רק אם שולם) |
| **ותק במערכת** | מ-`participants.first_enrolled_at` (ההרשמה הראשונה לבית הספר) |
| **כיתה** | ערך בודד על התלמיד: גן, א׳, ב׳, ג׳, ד׳, ה׳, ו׳, ז׳, ח׳, ט׳, י׳-י״ב |
| **כיתה — חובה** | חובה בהרשמה; מעל גיל 18 — כיתה לא חובה |
| **מגדר** | `male` / `female` על `participants` |
| **מגדר — מקור** | ידני בהרשמה; השלמה מגיליון Google Sheets (שלב 3) |
| **כיתה — מקור** | השלמה ידנית בלבד |
| **דוחות ואנליטיקה** | מנהלים + מפתח מערכת (Owner) בלבד |
| **התראות תפעוליות** | משרד + מנהלים (שלב עתידי) |
| **הכנסה למדריך** | סכום ששילמו תלמידים בחוגים שלו — **לא** כולל שכר המדריך |
| **ותק מדריך** | `profiles.hired_at` (ברירת מחדל: תאריך כניסה למערכת; מנהל יכול לערוך) |
| **סיכון עזיבה** | לא חידש לעונה הבאה **וגם** היעדרויות ממושכות |
| **התראת היעדרות** | 3 שיעורים ברצף ללא הגעה |
| **מדד בריאות** | תפוסה (עדיפות ראשונה); יחס עוזבים/חדשים (שני); ספי צבע — מנהל מגדיר |

### RPCs אנליטיקה (שלב 2)

כל 10 RPCs + `cc_active_student_ids` הורצו ב-Supabase (`command_center_analytics_part_01`…`11`).  
בדיקה מ-SQL Editor ללא JWT מנהל מחזירה `{}` — צפוי; מהאפליקציה כמנהל יוחזרו נתונים.

### הרצת סנכרון מלא (CLI)

```bash
# דוח ללא DB
node scripts/resync-from-sheets.mjs --both --annual data/import/stream-line-2025-26.xlsx --summer data/import/summer-2026.xlsx --parse-only

# dry-run מול DB (דורש SERVICE_ROLE_KEY ב-.env)
node scripts/resync-from-sheets.mjs --both --annual data/import/stream-line-2025-26.xlsx --summer data/import/summer-2026.xlsx --dry-run

# ריצה אמיתית
node scripts/resync-from-sheets.mjs --both --annual data/import/stream-line-2025-26.xlsx --summer data/import/summer-2026.xlsx
```
